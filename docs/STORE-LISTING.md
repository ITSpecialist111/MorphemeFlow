# MorphemeFlow — Chrome Web Store Listing

## Short Description (132 chars max)
Morpheme highlighting, syllable spacing, and adaptive typography for dyslexia reading support. Free, private, open source.

## Detailed Description

MorphemeFlow makes web text easier to read by breaking words into their meaningful parts (morphemes) and applying research-backed typography adjustments.

**How it works:**
- Highlights prefixes, roots, and suffixes in different colors so word structure is visible at a glance
- Adds micro-spacing between syllables to reduce visual crowding
- Applies dyslexia-friendly fonts, spacing, and background colors based on peer-reviewed research

**Features:**
- Three presets (Subtle, Balanced, Full) for quick setup
- Fine-grained sliders for every setting
- 5 bundled/system font choices: Lexend, Atkinson Hyperlegible, Verdana, System, OpenDyslexic
- 7 background themes including dark mode
- Reading ruler with focus, highlight, and underline modes
- Per-site enable/disable
- Keyboard shortcut (Ctrl+Shift+M) to toggle instantly
- Copy/paste preserves original text
- Semantic-content filtering avoids navigation, forms, editors, code, and hidden UI

**Privacy first:**
- Zero network requests — all processing happens on your device
- No analytics, no tracking, no accounts
- Fully open source (MIT license)

**Based on research:**
- Morpheme awareness training (Goodwin & Ahn, 2013)
- Knuth-Liang hyphenation algorithm (public domain)
- Typography research from pimpmytype.com and the Readability Group
- WCAG 2.1 AA accessibility standards

Works on standard reading pages and supported web applications. Browsers do not allow extensions to run on their own internal pages or extension stores. Free forever.
